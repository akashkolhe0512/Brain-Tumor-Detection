🧠 Brain Tumor Detection

AI-powered MRI analysis using deep learning to assist in brain tumor detection.

About the Project

This web application leverages Deep Learning and Computer Vision techniques to analyze brain MRI images. A trained neural network processes the uploaded scan and predicts whether a brain tumor is present.

How It Works

  • Upload a brain MRI image (JPG / PNG)
  • The image is resized and normalized
  • A CNN-based model analyzes the scan
  • The predicted tumor type is displayed

Why This Matters

Early detection of brain tumors can support faster diagnosis and improved treatment planning. This project demonstrates how AI can assist medical professionals in decision-making.
